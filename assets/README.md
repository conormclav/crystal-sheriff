# assets/

The sound pack shared with *Crystal Sheriff: Tower Defender*. All sprites are drawn with canvas
code and the rapid-fire click blips are synthesised with the Web Audio API, so the game still runs
if this folder is empty — you just lose music and the fanfare samples.

All files are community packs from Pixabay / freesound (Pixabay's licence allows free use in
games), keeping their original uploader names:
